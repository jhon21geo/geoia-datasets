# geoia-datasets

Datos de GeoIA.

## 1. Espectros

Ocho espectros TerraSpec (`.sco`): `10000.sco` a `10007.sco`.

## 2. Superficie

Geoquímica de superficie INGEMMET en `Data Ingemmet.csv` (coordenadas, proyecto y elementos).

## 3. Sondajes sintéticos

Intervalos de sondajes sintéticos:

- `DDH_lito.csv` — litología
- `DDH_alte.csv` — alteración e intensidad
- `DDH_assay.csv` — geoquímica
- `DDH_terraspec.csv` — minerales TerraSpec
